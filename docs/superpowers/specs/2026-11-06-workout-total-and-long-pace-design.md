# Workout total distance and long-run pace

**Status:** Approved; implementation complete.

## Intent

Show the runner the total distance for each complete session, including warm-up, main workout, and cool-down. For long runs, make the prescribed pace explicit in the workout text, for example `4,75 km a 6:40 min/km`.

## Existing behavior

The preview already has a separate total-distance column, but its “Treino principal” cell is generated by `formatCompleteWorkout`, which only joins segment labels. Long-run segments have pace labels, while the session-level description remains generic. The same formatter feeds the XLSX, so a shared change can keep both outputs consistent. `WorkoutSession.distanceKm` is the canonical total assigned across all workout segments.

## Goals

- Prefix each workout description with its total session distance using Brazilian number formatting.
- For `long` sessions, include the session's prescribed pace in `min/km`.
- Keep the detailed warm-up, main, recovery, and cool-down segment labels and their individual paces.
- Apply the same formatted text in the web preview and XLSX.

## Non-goals

- Change workout distances, training paces, periodization, or how the total is calculated.
- Add a single representative pace to quality workouts, which contain multiple paces.
- Change table columns, timeline dimensions, or training-plan generation.

## Approaches

1. **Update the shared workout formatter (chosen):** use `session.distanceKm` for every session and add `session.paceSecondsPerKm` only for long runs, then append the existing segment details. This preserves identical workout text in the preview and XLSX; it adds a short summary that may repeat the distance already shown in the table.
2. **Update only the web preview:** avoids touching export behavior, but leaves the XLSX inconsistent with the on-screen session text.
3. **Rewrite long-run descriptions in the plan generator:** would duplicate formatting logic and still would not add a total summary consistently to all workout types.

## Constraints and acceptance

- Keep all generated segment details in their current order.
- Format distance in `pt-BR` with two decimal places and pace through the existing `formatPace` helper.
- Long-run summary must contain the complete session distance and an explicit pace such as `6:40 min/km`; other workout types must not imply a single overall pace.
- Focused tests must verify the total includes all session phases and that only long runs get the single-pace summary.
